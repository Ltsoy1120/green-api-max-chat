# GREEN-API MAX Chat

Тестовое задание на должность Frontend Developer React.

Простой чат для отправки и получения текстовых сообщений в MAX через GREEN-API.

## Стек

React, TypeScript, SCSS, Vite, GREEN-API

## Запуск

```bash
npm install
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:5173`.

Для работы необходимо создать и авторизовать MAX-инстанс GREEN-API, затем ввести `idInstance` и `apiTokenInstance` в форме входа.
